# Kokonoe / Коконоэ<br>
Любительская графическая оболочка для windows<br>
Публичный репозиторий, без исходного кода, для массового пользования<br>
# Техническая информация<br>
Актулальный релиз - MVP 1.0 release<br>
Реализация - Qt 5.15.14<br>
Оболочка предназначена только для 64-разрядных версий Windows, для Windows 7 и выше
